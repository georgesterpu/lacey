# Found something that needs a quiet word?

Please report security vulnerabilities through
[GitHub’s private vulnerability reporting](https://github.com/georgesterpu/lacey/security/advisories/new).
Include enough detail to reproduce the issue with test data.

Please don’t put credentials, email addresses, confirmation or unsubscribe
tokens, customer exports or production backups in a public issue or pull request.
Use your own account and a local test database when investigating.

The production operations repository and its backup artifacts stay private.
Public CI uses isolated fixtures and never needs live database or email keys.
